# Stress test-audio set: sources and build notes

Built by [`build-stress-set.sh`](https://github.com/paulpengtw-aiagent/noScribe-live/blob/live-stress/live/samples/stress/build-stress-set.sh) in this folder. Run `bash live/samples/stress/build-stress-set.sh` from the repo root. The media files are git-ignored (see `live/.gitignore`). Downloads go to `dl/` (also ignored). The build reuses the LibriVox files that `live/samples/make-demo-clip.sh` already fetched into `live/samples/dl-en/` and `live/samples/dl-zh/`. The only new download is the third reader (about 2.2 MB).

## Sources

All real speech comes from LibriVox readings hosted on archive.org. Every source is public domain or CC0. The Wikimedia Commons searches did not yield a usable clip. The Taiwanese-Mandarin search returned only historical public-domain speeches (Sun Yat-sen, Wang Jingwei), which are not Taiwanese Mandarin. The Apollo air-to-ground search returned only images and PDFs. The next Commons query then got HTTP 429 (rate limit), so the Musopen music search never ran.

## Fallbacks and gaps

- **Taiwanese Mandarin (02):** not found. The Commons searches turned up no CC or PD Taiwanese-accent speech within the time box, so 02 and 06 use the LibriVox Mandarin reading. Its accent is not verified as Taiwanese.
- **Real multi-speaker conversation (03):** not found. The Apollo air-to-ground search returned only images and PDFs, and the next Commons query was rate-limited (HTTP 429). 03 is synthetic, built from three LibriVox readers.
- **Real code-switching (04):** not found, so 04 is a synthetic splice.
- **Background music (05):** none obtained (the Commons probe was rate-limited before the Musopen search ran). The fallback is pink noise plus babble.
- **06:** a single LibriVox chapter (11.6 min) covers the 10-12 minute requirement.
